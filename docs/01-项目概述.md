# 拼多多智能客服系统 — 项目概述

## 项目背景

基于 AI 的拼多多智能客服系统，通过视觉 RPA 技术模拟人工客服操作：
- 从拼多多商家工作台接收客户消息
- 使用 LLM 生成专业回复
- 模拟鼠标键盘操作自动在客户端发送回复
- 记录和分析客户反馈问题

## 整体架构

```
┌──────────────────────────────┐
│   拼多多商家工作台（桌面端）     │
└───────────┬──────────────────┘
            │ 屏幕截图
            ▼
┌──────────────────────────────┐
│   视觉感知模块                │
│   - mss 快速局部截屏           │
│   - PaddleOCR 文字识别        │
│   - OpenCV 模板匹配           │
└───────────┬──────────────────┘
            │ 结构化数据
            ▼
┌──────────────────────────────┐
│   调度与决策模块               │
│   - 消息检测与队列管理         │
│   - Prompt 组装（知识库+历史）  │
│   - MiniMax M2.7 LLM 调用    │
└───────────┬──────────────────┘
            │ 操作指令
            ▼
┌──────────────────────────────┐
│   操作执行模块                │
│   - pyautogui 鼠标点击        │
│   - 键盘输入                  │
│   - 发送确认                  │
└───────────┬──────────────────┘
            │
            ▼
┌──────────────────────────────┐
│   数据记录与分析模块           │
│   - SQLite 对话日志存储       │
│   - 问题分类与报表             │
└──────────────────────────────┘
```

## 技术选型

| 层级 | 技术 | 说明 |
|------|------|------|
| 屏幕截图 | Python + mss | 高速局部截屏 |
| OCR | PaddleOCR | 中文识别准确率高，本地运行 |
| 模板匹配 | OpenCV | 定位按钮、红点等固定UI元素 |
| LLM | MiniMax M2.7 | 多模态，文字+图片理解 |
| 鼠标键盘 | pyautogui | 模拟点击和输入 |
| 数据存储 | SQLite | 轻量单机数据库 |
| 开发语言 | Python | 生态最适合 RPA+AI 场景 |

## 分阶段规划

| 阶段 | 目标 | 状态 |
|------|------|------|
| Phase 1 | 最小可用链路：单店铺单会话自动回复 | 开发中 |
| Phase 2 | 单 Tab 多会话轮询 + 未读检测 | 待开发 |
| Phase 3 | 多 Tab 跨店铺轮询 | 待开发 |
| Phase 4 | 生产加固：转人工、异常恢复、报表 | 待开发 |
