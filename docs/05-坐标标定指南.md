# 坐标标定指南

## 为什么要标定坐标

拼多多商家工作台使用自绘界面（CEF/Electron 套壳），无法通过 UI Automation 获取控件位置。
因此需要手动标定各功能区域的屏幕坐标。

## 方法一：使用 calibrate.py 工具

```bash
python tools/calibrate.py
```

交互流程：
1. 程序会截取全屏并显示
2. 按照提示依次点击：对话区域左上角 → 对话区域右下角 → 输入框中心 → 发送按钮中心
3. 程序自动计算坐标并保存到 `config/coordinates.local.yaml`

## 方法二：手动标定

### 步骤

1. 打开拼多多商家工作台，定位到某个客户对话窗口
2. 按 `Print Screen` 截取全屏
3. 打开 Windows 画图工具（mspaint），粘贴截图
4. 将鼠标移动到各位置，左下角会显示像素坐标

### 需要标定的区域

| 区域 | 说明 |
|------|------|
| `chat_area` | 对话内容显示区域（包含聊天记录的区域） |
| `input_box` | 文本输入框区域 |
| `send_button_center` | 发送按钮的中心位置 |
| `input_box_center` | 输入框的中心位置（点击后获得焦点） |

### 坐标记录

将坐标填入 `config/coordinates.yaml`：

```yaml
chat_area:
  x: <左上角X>
  y: <左上角Y>
  width: <宽度>
  height: <高度>
```

宽高 = 右下角坐标 - 左上角坐标

## 模板截图

除了坐标，还需要截取以下 UI 元素的小图（用于 OpenCV 模板匹配）：

1. **发送按钮** (`docs/templates/send_button.png`)
   - 截取发送按钮的清晰图标/文字
   - 使用截图工具截取约 40x40 像素的区域

2. **输入框** (`docs/templates/input_box.png`)
   - 截取输入框的边框或背景特征区域

3. **未读标记** (`docs/templates/unread_badge.png`)
   - Phase 2 使用，截取未读消息的红点标记

## 验证方法

标定完成后，运行调试模式验证：
```bash
# 在 config/default.yaml 中设置：
# operator.debug_mode: true
# screenshot.save_debug: true

python src/main.py
```

检查 `data/screenshots/` 中的调试截图，确认截取的区域是否正确。
