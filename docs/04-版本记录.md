# 版本记录

## 版本号规则

`v<phase>.<major>.<minor>`

- **phase**: 对应开发阶段 (1=单店铺单会话, 2=多会话轮询, 3=多Tab轮询, 4=生产加固)
- **major**: 大功能迭代
- **minor**: 小修复/调优
