# 配置说明

## 配置文件概述

```
config/
├── default.yaml              # 主配置（逻辑参数）
├── default.local.yaml        # 本地密钥覆盖（gitignored）
├── coordinates.yaml          # 屏幕坐标配置
└── coordinates.local.yaml    # 本地坐标覆盖（gitignored）
```

**加载优先级（后者覆盖前者）：**
1. `default.yaml` — 基础配置
2. `default.local.yaml` — 本地密钥覆盖（仅覆盖敏感字段）
3. `coordinates.yaml` — 坐标配置
4. `coordinates.local.yaml` — 本地坐标覆盖（每台机器不同）

## default.local.yaml

用于在本地覆盖 `default.yaml` 中的敏感字段（如 API Key），**不提交到 git**。只需填写需要覆盖的字段，其余仍沿用 `default.yaml` 的值：

```yaml
# config/default.local.yaml
llm:
  api_key: "your_api_key_here"
```

也可覆盖多个字段，例如同时覆盖模型名和超时：

```yaml
llm:
  api_key: "your_api_key_here"
  model: "minimax-m2.7"
  timeout: 30
```

> 建议始终用此文件配置 `api_key`，避免密钥泄露到 git 仓库。

## default.yaml 主要字段

### LLM 配置
```yaml
llm:
  provider: "minimax"            # LLM 供应商
  api_key: ""                    # API 密钥（直接填入即可）
  model: "minimax-m2.7"            # 模型名称
  base_url: "https://api.minimax.chat/v1"
  timeout: 15                    # 请求超时（秒）
  max_retries: 3                 # 失败重试次数
  temperature: 0.7               # 生成温度
  max_output_tokens: 500         # 最大输出 token
```

### 截屏配置
```yaml
screenshot:
  interval: 1.5                  # 轮询间隔（秒）
  save_debug: false              # 是否保存调试截图
  debug_dir: "./data/screenshots"
```

### OCR 配置
```yaml
ocr:
  confidence_threshold: 0.7      # 置信度阈值，低于此值的结果丢弃
  use_gpu: false                 # PaddleOCR GPU 加速（需 CUDA）
```

### 操作配置
```yaml
action:
  type_delay: 0.05               # 打字字符间延迟（秒）
  click_delay: 0.3               # 点击后等待（秒）
  random_delay_range: [0.5, 1.5] # 操作间随机延时范围
```

### 上下文配置
```yaml
context:
  max_history_rounds: 20         # 注入 prompt 的最大历史轮数
  retention_days: 3              # 上下文保留天数
  session_idle_minutes: 30       # 会话闲置超时（分钟）
```

### 运行模式
```yaml
operator:
  debug_mode: false              # 调试模式：仅截图和OCR，不操作
  demo_mode: false               # 演示模式：用模拟回复替代真实 API
```

## coordinates.yaml 配置

所有坐标相对商家工作台窗口左上角。

```yaml
window:
  offset_x: 0                    # 窗口 X 偏移
  offset_y: 0                    # 窗口 Y 偏移

chat_area:                       # 对话内容区域
  x: 380
  y: 120
  width: 820
  height: 580

input_box:                       # 输入框区域
  x: 380
  y: 720
  width: 760
  height: 80

send_button_center:              # 发送按钮中心点
  x: 1170
  y: 760

input_box_center:                # 输入框中心点
  x: 760
  y: 760
```

## 坐标校准

使用 `tools/calibrate.py` 辅助标定坐标：
```bash
python tools/calibrate.py
```

或手动标定：
1. 截取商家工作台全屏截图
2. 用画图工具打开截图
3. 鼠标移动到各区域的左上角和右下角，记录坐标
4. 填入 `coordinates.yaml`
