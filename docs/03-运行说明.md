# 运行说明

## 环境要求

- **操作系统**: Windows 10 或 Windows 11
- **Python**: 3.8+
- **拼多多商家工作台**: 已安装并登录
- **分辨率**: 固定（坐标配置依赖固定分辨率）

## 安装步骤

### 1. 克隆项目
```bash
git clone <repo_url>
cd pdd-cs
```

### 2. 创建虚拟环境（推荐）
```bash
python -m venv venv
.\venv\Scripts\activate
```

### 3. 安装依赖
```bash
pip install -r requirements.txt
```

PaddleOCR 首次运行时会自动下载中文识别模型（约 10-15MB），请确保网络畅通。

### 4. 配置 API Key

编辑 `config/default.yaml`，在 `llm.api_key` 字段中填入密钥：
```yaml
llm:
  api_key: "your_api_key_here"
```

### 5. 配置坐标

首次运行前需要标定屏幕坐标：
1. 打开拼多多商家工作台
2. 定位到一个客户对话窗口
3. 运行坐标标定工具：`python tools/calibrate.py`
4. 或手动编辑 `config/coordinates.yaml`

## 运行

### 正常模式
```bash
python src/main.py
```

### 演示模式（无需 API Key，使用模拟回复）
编辑 `config/default.yaml`：
```yaml
operator:
  demo_mode: true
```

### 调试模式（截图+OCR，不执行实际操作）
编辑 `config/default.yaml`：
```yaml
operator:
  debug_mode: true
  save_debug: true   # 保存调试截图到 data/screenshots/
```

## 运行前准备

1. 打开拼多多商家工作台
2. 确保窗口可见（不被遮挡或最小化）
3. 手动定位到要处理的客户对话窗口
4. 运行 `python src/main.py`

## 停止

按 `Ctrl+C` 优雅停止。

## 故障排查

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| 截屏为黑屏 | 窗口被遮挡/最小化 | 确保商家工作台窗口前台可见 |
| OCR 识别为空 | 字体/颜色/分辨率问题 | 降低 `ocr.confidence_threshold`，检查坐标 |
| LLM 调用失败 | API Key 错误/网络不通 | 检查 `llm.api_key` 和网络 |
| 点击位置偏移 | 坐标不匹配 | 重新运行 `tools/calibrate.py` 校准 |
| PaddleOCR 初始化失败 | 模型下载失败 | 手动下载模型到 `~/.paddleocr/` |

## 远程管理

使用 ToDesk 或向日葵远程连接到专用机器，查看运行状态和日志。
